📜 Спавн предметов
Чтобы получить необходимые предметы с помощью консоли, необходимо выполнить следующие шаги (для использования команд необходимо быть создателем сервера):

Важно! Консоль по умолчанию отключена. Для её включения необходимо добавить аргумент запуска "-console"

Шаг 1. Открываем консоль клавишей F5

Шаг 2. Активируем команды разработчика, введя команду devcommands и нажав Enter

Шаг 3. Спавним нужный нам предмет командой spawn с указанием его ID и количества (для существ можно дополнительно указать уровень). После нажимаем Enter

Например, нам необходимо 100 древесины. Команда будет выглядеть так: spawn Wood 100
Если необходим волк 2-го уровня, то команда будет выглядеть так: spawn Wolf 1 3

Шаг 4 (опционально). Деактивируем команды разработчика, введя команду devcommands и нажав Enter
